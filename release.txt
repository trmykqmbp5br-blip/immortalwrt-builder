ImmortalWrt 24.10.6 x86_64 自动构建固件

内核: Linux 6.6 | 架构: x86_64 (Intel/AMD)
平台: ImmortalWrt 24.10.6 官方源码
特性: IA32_EMULATION (musl+glibc双运行时) | mwan3 双WAN | SmartDNS | Docker | BBR

默认设置:
 - 管理IP: 192.168.100.1
 - 用户名: root
 - 已预置 SSH 公钥认证

固件文件说明:
 - *squashfs-combined-efi.img.gz — factory 刷机包（第一次刷写用）
 - *squashfs-sysupgrade.bin — 在线升级包（Web/命令行升级用）

刷写方式:
 1. 第一次刷写: 使用 combined-efi.img.gz（解压后用写盘工具写入）
 2. 在线升级: Web 界面 系统 → 备份/升级 → 刷写固件，或命令行 sysupgrade -f backup.tar.gz <sysupgrade.bin>

首次启动时 99-custom.sh 会动态检测网口并配置网络。
单网口: DHCP 模式，WAN 防火墙开放以允许 WebUI 访问
多网口: 静态 IP，WAN 为 DHCP（如构建时启用 PPPoE 则使用 PPPoE）

Release 中仅保留最近 3 个构建，旧版本会被自动清理。
