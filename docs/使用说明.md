# ImmortalWrt Builder — 构建说明

## 概述

基于 GitHub Actions 的 ImmortalWrt 24.10.6 x86_64 固件自动构建。所有包均从 ImmortalWrt 官方源码编译，无预编译 ipk 注入。

---

## build.yml（完整）

```yaml
name: Build ImmortalWrt x86_64

on:
  workflow_dispatch:
    inputs:
      repo_branch:
        description: 'ImmortalWrt 分支或 Tag'
        required: true
        default: 'master'
        type: string
      rootfs_size:
        description: 'Rootfs size (MB)'
        required: true
        default: '4096'
      include_docker:
        description: 'Include Docker'
        required: true
        default: 'yes'
        type: choice
        options:
          - 'yes'
          - 'no'

permissions:
  contents: write
  actions: write

env:
  REPO_URL: https://github.com/immortalwrt/immortalwrt
  REPO_BRANCH: ${{ github.event.inputs.repo_branch }}
  TZ: Asia/Shanghai

jobs:
  build:
    runs-on: ubuntu-22.04
    timeout-minutes: 540

    steps:
    - name: Prepare environment
      env:
        DEBIAN_FRONTEND: noninteractive
      run: |
        echo "=== 释放磁盘空间 ==="
        sudo rm -rf /opt/hostedtoolcache /usr/share/dotnet /usr/local/lib/android /usr/local/share/powershell /usr/local/.ghcup /usr/local/julia* /opt/ghc
        sudo docker image prune --all --force 2>/dev/null || true
        sudo swapoff -a 2>/dev/null || true
        sudo dd if=/dev/zero of=/swapfile bs=1M count=4096 status=none 2>/dev/null
        sudo mkswap /swapfile 2>/dev/null && sudo swapon /swapfile 2>/dev/null
        echo "=== 安装构建依赖 ==="
        sudo timedatectl set-timezone "$TZ"
        sudo mkdir -p /workdir
        sudo chown $USER:$GROUPS /workdir
        sudo apt-get update -y || {
          echo "apt-get update timeout, retrying..."
          sudo apt-get update -y
        }
        sudo apt-get install -y --no-install-recommends \
          antlr3 asciidoc autoconf automake autopoint binutils bison build-essential \
          bzip2 ccache clang cmake cpio curl device-tree-compiler e2fsprogs fastjar flex gawk gettext \
          gcc-multilib g++-multilib git gperf haveged help2man intltool libc6-dev-i386 \
          libelf-dev libfuse-dev libglib2.0-dev libgmp3-dev libltdl-dev libmpc-dev libmpfr-dev \
          libncurses-dev libpython3-dev libreadline-dev libssl-dev libtool libyaml-dev libz-dev \
          lld llvm lrzsz mkisofs msmtp nano ninja-build p7zip p7zip-full patch pkgconf \
          python3 python3-pip python3-pyelftools python3-setuptools qemu-utils re2c rsync \
          scons squashfs-tools subversion swig texinfo uglifyjs upx-ucl unzip vim wget xmlto \
          xxd zlib1g-dev zstd
        sudo apt-get clean
        sudo rm -rf /var/lib/apt/lists/* /var/cache/apt/*
        df -hT /

    - name: Checkout
      uses: actions/checkout@v6

    - name: Clone source code
      working-directory: /workdir
      run: |
        df -hT $PWD
        git clone $REPO_URL -b $REPO_BRANCH openwrt
        ln -sf /workdir/openwrt $GITHUB_WORKSPACE/openwrt

    - name: Get date for cache key
      id: cache-date
      run: echo "date=$(/bin/date -u "+%Y%m%d")" >> "$GITHUB_OUTPUT"

    # ====== dl 缓存 ======
    - name: Restore dl cache
      uses: actions/cache/restore@v5
      with:
        path: /workdir/openwrt/dl/
        # 末尾加 '-' 使其变成前缀匹配
        key: dl-${{ env.REPO_BRANCH }}-${{ steps.cache-date.outputs.date }}-${{ hashFiles('diy-part1.sh', 'scripts/kernel-config.sh') }}-
        restore-keys: |
          dl-${{ env.REPO_BRANCH }}-${{ steps.cache-date.outputs.date }}-
          dl-${{ env.REPO_BRANCH }}-

    - name: Configure feeds
      run: bash diy-part1.sh

    - name: Apply custom config
      env:
        ROOTFS_SIZE: ${{ github.event.inputs.rootfs_size }}
        INCLUDE_DOCKER: ${{ github.event.inputs.include_docker }}
      run: bash diy-part2.sh

    - name: Download sources
      working-directory: /workdir/openwrt
      run: make download -j$(nproc)

    - name: Save dl cache on success
      if: success()
      uses: actions/cache/save@v5
      with:
        path: /workdir/openwrt/dl/
        key: dl-${{ env.REPO_BRANCH }}-${{ steps.cache-date.outputs.date }}-${{ hashFiles('diy-part1.sh', 'scripts/kernel-config.sh') }}-run_${{ github.run_id }}

    # ====== ccache 缓存 ======
    - name: Restore ccache
      uses: actions/cache/restore@v5
      with:
        path: /home/runner/.ccache
        key: ccache-${{ env.REPO_BRANCH }}-${{ steps.cache-date.outputs.date }}-
        restore-keys: |
          ccache-${{ env.REPO_BRANCH }}-${{ steps.cache-date.outputs.date }}-
          ccache-${{ env.REPO_BRANCH }}-

    - name: Compile firmware
      working-directory: /workdir/openwrt
      run: |
        chown -R runner:runner /home/runner/.ccache || true
        su - runner -c "ccache -z && ccache -M 5G"
        make -j2 V=1 CONFIG_CCACHE=y CONFIG_CCACHE_DIR="/home/runner/.ccache"

    - name: ccache stats
      if: always()
      run: |
        echo "=== ccache stats ==="
        su - runner -c "ccache -s" 2>/dev/null || true
        SIZE=$(ccache -s 2>/dev/null | grep -i 'cache size' | grep -oP '[\d.]+(?=\s*G)' || echo "0")
        if [ -n "$SIZE" ] && [ "$(echo "$SIZE > 6" | bc 2>/dev/null)" = "1" ]; then
          echo "ccache exceeds 6GB ($SIZE GB), clearing..."
          ccache -C 2>/dev/null || true
        fi

    - name: Save ccache on success
      if: success()
      uses: actions/cache/save@v5
      with:
        path: /home/runner/.ccache
        key: ccache-${{ env.REPO_BRANCH }}-${{ steps.cache-date.outputs.date }}-run_${{ github.run_id }}

    - name: Save ccache on failure
      if: failure()
      uses: actions/cache/save@v5
      with:
        path: /home/runner/.ccache
        key: ccache-${{ env.REPO_BRANCH }}-${{ steps.cache-date.outputs.date }}-failed-run_${{ github.run_id }}

    - name: Release firmware
      if: success()
      env:
        GH_REPO: ${{ github.repository }}
        GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
      run: |
        cd /workdir/openwrt/bin/targets/x86/64/
        IMG_FILE=$(find . -name "*combined*img.gz" -type f | head -n 1)
        BIN_FILE=$(find . -name "*sysupgrade.bin" -type f | head -n 1)
        TAG="${{ env.REPO_BRANCH }}-$(date +%Y%m%d-%H%M)"
        TITLE="ImmortalWrt ${{ env.REPO_BRANCH }} Build $(date +%Y-%m-%d)"
        cat > release_notes.md << NOTEEOF
        **分支/版本**: ${{ env.REPO_BRANCH }}
        **Docker支持**: ${{ github.event.inputs.include_docker }}
        **Rootfs大小**: ${{ github.event.inputs.rootfs_size }}MB

        **${IMG_FILE}** - 物理刷机
        **${BIN_FILE}** - 在线升级
        NOTEEOF
        echo "Creating release ${TAG}..."
        gh release create "${TAG}" ${IMG_FILE} ${BIN_FILE} --title "${TITLE}" --notes-file release_notes.md
        echo "Cleaning up old releases (keep latest 3)..."
        gh release list --limit 50 | tail -n +4 | awk '{print $1}' | while read -r tag; do
          gh release delete "${tag}" -y
        done
```

## diy-part2.sh（自定义配置）

```bash
#!/bin/bash
set -e
cd /workdir/openwrt

# 1. 下载 kconfig-tool
wget -O scripts/kconfig-tool https://raw.githubusercontent.com/torvalds/linux/master/scripts/config
chmod +x scripts/kconfig-tool scripts/*.sh

# 2. 注入 32 位运行时库到 files/（如果脚本存在则执行，不存在则跳过）
if [ -f scripts/runtime-musl32.sh ]; then
    bash scripts/runtime-musl32.sh
else
    echo "⚠️ scripts/runtime-musl32.sh not found, skipping."
fi

if [ -f scripts/runtime-glibc32.sh ]; then
    bash scripts/runtime-glibc32.sh
else
    echo "⚠️ scripts/runtime-glibc32.sh not found, skipping."
fi

# 3. 🚨 关键修复：写入目标平台种子配置
cat > .config <<EOF
CONFIG_TARGET_x86=y
CONFIG_TARGET_x86_64=y
EOF

# 4. 生成标准 .config（基于种子扩展出完整配置）
make defconfig

# 5. 注入内核补丁与 Docker 内核依赖
bash scripts/kernel-config.sh

# 5.5 注入内核编译期 olddefconfig 补丁
if [ -f scripts/kernel-config-patch.py ]; then
    python3 scripts/kernel-config-patch.py
else
    echo "⚠️ scripts/kernel-config-patch.py not found, skipping."
fi

# 6. 启用 CCACHE 强锁
./scripts/kconfig-tool --enable CONFIG_CCACHE
./scripts/kconfig-tool --set-str CONFIG_CCACHE_DIR "/home/runner/.ccache"

# 7.（可选）强制启用需要源码编译的包
# ./scripts/kconfig-tool --enable CONFIG_PACKAGE_docker
# ./scripts/kconfig-tool --enable CONFIG_PACKAGE_dockerd

# 8. 设置 rootfs 大小（从环境变量读取，默认 4096）
if [ -n "$ROOTFS_SIZE" ]; then
    ./scripts/kconfig-tool --set-val CONFIG_TARGET_ROOTFS_PARTSIZE "$ROOTFS_SIZE"
fi

# 9. 安全地解决新引入的内核依赖
make olddefconfig

echo "✅ diy-part2: Native config applied with 32-bit & Docker kernel support."
```

## scripts/kernel-config.sh（内核配置）

```bash
#!/bin/bash
cd /workdir/openwrt

# 自动探测 x86/64 下的内核配置文件
KERNEL_CONFIG_FILE=$(ls target/linux/x86/64/config-* 2>/dev/null | head -n 1)

if [ -z "$KERNEL_CONFIG_FILE" ]; then
    echo "❌ Error: Kernel config file not found in target/linux/x86/64/"
    exit 1
fi

echo "📌 Patching kernel config: $KERNEL_CONFIG_FILE"

# ==== 基础配置（始终启用）====
cat >> "$KERNEL_CONFIG_FILE" <<EOF

# === Custom: 32-bit support ===
CONFIG_IA32_EMULATION=y
EOF

# ==== Docker 内核依赖（仅在 INCLUDE_DOCKER=yes 时启用）====
if [ "$INCLUDE_DOCKER" = "yes" ]; then
    cat >> "$KERNEL_CONFIG_FILE" <<DOCKEREOF

# === Custom: Docker required modules ===
CONFIG_VETH=y
CONFIG_MACVLAN=y
CONFIG_IPVLAN=y
CONFIG_VXLAN=y
CONFIG_NETFILTER_XT_MATCH_ADDRTYPE=y
CONFIG_NETFILTER_XT_MATCH_IPVS=y
CONFIG_IP_VS=y
CONFIG_IP_VS_NFCT=y
CONFIG_IP_VS_RR=y
CONFIG_CGROUP_PIDS=y
CONFIG_MEMCG=y
DOCKEREOF
fi
```

## 缓存策略

### dl 缓存

- key 含日期 + feeds 配置哈希（`diy-part1.sh`、`scripts/kernel-config.sh`），每天一份
- 恢复时先精确匹配当天哈希 → 回退当天任意版本 → 回退最近分支
- 保存时追加 `run_${{ github.run_id }}`，每次构建写入独立条目，互不覆盖

### ccache 缓存

- 编译命令通过 `CONFIG_CCACHE=y CONFIG_CCACHE_DIR="/home/runner/.ccache"` 强锁
- 确保 OpenWrt `rules.mk` export 的路径与 cache action 一致
- 编译前 `ccache -z` 重置统计 + `ccache -M 5G` 限容
- 保存同日期 + run_id 格式

**`/home/runner/.ccache` 不可改为 `~` 或 `$HOME`**，否则缓存版本计算不一致导致旧缓存失效。

---

## 32 位应用支持

- 内核 `CONFIG_IA32_EMULATION=y`
- 预置 musl 32-bit 和 glibc 32-bit 双运行时
- `files/usr/bin/run-i386` 自动识别 musl/glibc 二进制
- `scripts/runtime-musl32.sh`、`scripts/runtime-glibc32.sh` 在 diy-part2.sh 中自动执行

---

## Docker 支持

Docker 必需的内核模块在 `scripts/kernel-config.sh` 中通过 kconfig-tool 强制启用：

| 类别 | 选项 |
|------|------|
| 网络虚拟化 | VETH, MACVLAN, IPVLAN, VXLAN |
| Netfilter | NETFILTER_XT_MATCH_ADDRTYPE, NETFILTER_XT_MATCH_IPVS, IP_VS, IP_VS_RR |
| Cgroup | CGROUP_PIDS, MEMCG |

---

## 维护注意事项

1. **kconfig-tool 后绝不再执行 make defconfig** — 启用 CCACHE 后 defconfig 可能重置值，用 `make olddefconfig` 代替
2. **CCACHE 路径必须硬编码** — `/home/runner/.ccache` 不可用 `~`，否则缓存 miss
3. **add feeds 在 diy-part1.sh** — 如需第三方 feed，取消注释添加源即可
4. **强制启用包在 diy-part2.sh** — 按需取消注释 `./scripts/kconfig-tool --enable CONFIG_PACKAGE_xxx`
