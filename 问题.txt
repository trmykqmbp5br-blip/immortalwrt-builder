 你的 immortalwrt-builder 项目有 3 个配置问题导致 Docker 起不来：

  问题 1（核心）：iptables-nft 没编入固件

  .config 中：
  CONFIG_PACKAGE_iptables-nft=m   ← 只编译 .ipk，不嵌入 squashfs
  CONFIG_PACKAGE_ip6tables-nft=m  ← 同上

  在 OpenWrt 里 =m 表示"编译但不打包进固件"。所以刷机后系统里没有 iptables 命令，Docker 启动时直接挂：

  failed to create NAT chain DOCKER: iptables not found

  修复：scripts/docker-toggle.sh 里要加这两行：

  sed -i 's/.*CONFIG_PACKAGE_iptables-nft.*/CONFIG_PACKAGE_iptables-nft=y/' .config
  sed -i 's/.*CONFIG_PACKAGE_ip6tables-nft.*/CONFIG_PACKAGE_ip6tables-nft=y/' .config

  问题 2：overlay2 存储驱动无法工作

  固件类型是 squashfs（CONFIG_TARGET_ROOTFS_SQUASHFS=y），根文件系统是 overlayfs 叠加。Docker 的 overlay2 驱动不能在
  overlayfs 上再叠 overlay。所以报：

  overlay: filesystem on /opt/docker/.../upper not supported as upperdir

  修复：在 files/etc/docker/daemon.json 预配置 Docker 数据目录到 f2fs 分区：

  {
    "storage-driver": "overlay2",
    "data-root": "/overlay/docker"
  }

  （/overlay 是底层 f2fs，不是 overlayfs，overlay2 可以正常工作）

  问题 3：Release 删掉了 packages 目录

  cd /workdir/openwrt/bin/targets/*/*
  rm -rf packages   ← 这一行

  即使 iptables-nft=m 编出了 .ipk，也被删掉了，刷机后想 opkg install 都没包可用。

  修复：保留 packages 目录，或至少把缺失的包写入 release notes。

  ---
  还有个小问题

  CONFIG_PACKAGE_fuse-overlayfs 也没开，不过用上面问题 2 的方案（data-root 指向 /overlay/docker）就不需要它了。

  总结
